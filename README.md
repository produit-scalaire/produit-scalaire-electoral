# Produit scalaire électoral

Comparateur d'affinités politiques : vos réponses et leur importance forment un vecteur, comparé par produit scalaire aux positions des partis.

- Page en ligne : https://produit-scalaire.github.io/produit-scalaire-electoral/
- `index.html` : la page complète (un seul fichier, fonctionne hors connexion)
- `catalogue-questions.html` : toutes les questions, regroupées par thème
- `source/` : `questions.json`, `template.html`, `disclaimer.md`, `animation-axes.html` et les scripts `build.py` / `build_catalogue.py` qui génèrent les pages
